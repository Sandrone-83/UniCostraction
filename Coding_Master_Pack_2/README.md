# Coding_Master_Pack_2 — Secondo livello di profondità

Materiale didattico che completa Coding_Master_Pack: sei aree che separano lo
sviluppatore bravo dall'ingegnere del software completo. 30 schede, sei corpus.

## Struttura

| Corpus | File | Schede | Contenuto |
|---|---|---|---|
| DevOps e infrastruttura | `parsed/devops_infrastruttura.jsonl` | 5 | Docker e container, CI/CD (blue/green, canary, feature flag), Kubernetes e IaC, osservabilità (metriche/log/tracing/allerte), cloud e FinOps |
| Frontend master | `parsed/frontend_master.jsonl` | 5 | React/Next.js da senior, CSS moderno e design system, web performance (Core Web Vitals), accessibilità WCAG, progetti frontend reali (landing, dashboard, configuratore) |
| Data & AI engineering | `parsed/data_ai_engineering.jsonl` | 5 | Pipeline dati ELT, data warehouse e modellazione a stella, ML engineering, fine-tuning e valutazione LLM, LLMOps |
| Rete e sistemi | `parsed/rete_sistemi.jsonl` | 5 | Networking per sviluppatori, HTTP avanzato e caching, transazioni e isolamento, replicazione e disaster recovery, performance di sistema |
| Craft avanzato | `parsed/craft_avanzato.jsonl` | 5 | Codice legacy (strangler fig), stime e pianificazione, regex e parsing, shell scripting e automazione, lettura strategica del codice |
| Progetti guidati | `parsed/progetti_guidati.jsonl` | 5 | Cinque progetti completi: CLI professionale, REST API produttiva, sistema RAG, chatbot con strumenti, mini-linguaggio per computi edili |

Formato: JSONL, una scheda JSON per riga (chiavi: id, categoria, tema, title,
text, source, license, commercial_ok, attribution, url).

## Relazione con Coding_Master_Pack

Il primo pack copre il nucleo (best practices, algoritmi, linguaggi, system
design, sicurezza, AI coding). Questo secondo pack copre la superficie
operativa completa: infrastruttura, frontend, dati e AI in produzione, rete,
il mestiere quotidiano e i progetti integrativi.
