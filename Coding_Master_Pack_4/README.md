# Coding_Master_Pack_4 — Quarto livello (nicchie finali)

Le ultime quattro aree non ridondanti della serie: consenso distribuito e
motori di storage, sviluppo videogiochi, metodi formali, computer vision con
applicazioni edili. 20 schede, quattro corpus. Con questo pack la serie coding
e' completa: ulteriori approfondimenti ricadrebbero in ripetizione.

## Struttura

| Corpus | File | Schede | Contenuto |
|---|---|---|---|
| Consenso e storage | `parsed/consensus_storage.jsonl` | 5 | Raft, B-Tree vs LSM, event sourcing e CRDT, transazioni distribuite, tempo e ordine |
| Game development | `parsed/game_development.jsonl` | 5 | Game loop ed ECS, fisica, netcode, generazione procedurale, progettare un gioco |
| Metodi formali | `parsed/metodi_formali.jsonl` | 5 | La scala della rigorosità, stati e invarianti, model checking, tipi come prove, quando usarli |
| Computer vision | `parsed/computer_vision.jsonl` | 5 | Immagini come tensori, visione classica e fotogrammetria, deep learning, visione 3D e scan-to-BIM, visione applicata al cantiere |

Formato: JSONL, una scheda JSON per riga.
